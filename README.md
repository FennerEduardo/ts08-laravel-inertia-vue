## Build and test

The commands below are the ones gherkin-ai uses to verify this stack. Run them in `generated-specs` with the toolchain installed, or inside the official image `composer:2`.

```bash
cd generated-specs
apk add --no-cache $PHPIZE_DEPS postgresql-dev linux-headers > /dev/null && docker-php-ext-install pdo_pgsql sockets > /dev/null
composer install --no-progress --prefer-dist -q
find app routes tests features contracts bootstrap -name "*.php" -print0 | xargs -0 -n1 php -l > /dev/null
php artisan --version
vendor/bin/phpunit --exclude-group integration
vendor/bin/behat --no-colors --format=progress
```

Runtime integration suite (IT1–IT7: transactional outbox, idempotency under concurrency, exactly-once relay, tenant isolation, saga compensation, inbox deduplication and dead-lettering, trace propagation):

```bash
docker run -d --name ghk-pg -e POSTGRES_PASSWORD=ghk -p 5432:5432 postgres:17-alpine
docker run -d --name ghk-mq -e RABBITMQ_DEFAULT_USER=ghk -e RABBITMQ_DEFAULT_PASS=ghk -p 5672:5672 rabbitmq:4-alpine
export DATABASE_URL=postgres://postgres:ghk@localhost:5432/postgres AMQP_URL=amqp://ghk:ghk@localhost:5672
vendor/bin/phpunit --group integration
```

Frontend (`generated-specs/frontend`, image `node:24-bookworm`):

```bash
cd generated-specs/frontend
npm install --no-audit --no-fund --loglevel=error
npm run build
npm test
```
