Reference project for [gherkin-ai](https://github.com/FennerEduardo/gherkin-ai-cli) 3.2.0. An authenticated checkout in Laravel 13 with a Vue 3 frontend.

Everything in `generated-specs/` was generated by `ghk generate` from the specification in `features/laravel_inertia_checkout.feature`. The project builds, and its generated tests and runtime integration suite pass, as verified on 2026-10-23 (see [Verification](#verification)).

## Build and test

The commands below are the ones gherkin-ai uses to verify this stack. Run them in `generated-specs` with the toolchain installed, or inside the official image `composer:2`.

```bash
cd generated-specs
apk add --no-cache $PHPIZE_DEPS postgresql-dev linux-headers > /dev/null && docker-php-ext-install pdo_pgsql sockets > /dev/null
composer install --no-progress --prefer-dist -q
find app routes tests features contracts bootstrap -name "*.php" -print0 | xargs -0 -n1 php -l > /dev/null
php artisan --version
vendor/bin/phpunit --exclude-group integration
vendor/bin/behat --no-colors --format=progress
```

Runtime integration suite (IT1–IT7: transactional outbox, idempotency under concurrency, exactly-once relay, tenant isolation, saga compensation, inbox deduplication and dead-lettering, trace propagation), plus an HTTP test of the generated API (tenant from the JWT, idempotency key, outbox):

```bash
docker run -d --name ghk-pg -e POSTGRES_PASSWORD=ghk -p 5432:5432 postgres:17-alpine
docker run -d --name ghk-mq -e RABBITMQ_DEFAULT_USER=ghk -e RABBITMQ_DEFAULT_PASS=ghk -p 5672:5672 rabbitmq:4-alpine
export DATABASE_URL=postgres://postgres:ghk@localhost:5432/postgres AMQP_URL=amqp://ghk:ghk@localhost:5672
vendor/bin/phpunit --group integration
```

The same suite runs against the Google Cloud Pub/Sub emulator. The gherkin-ai golden `laravel-pubsub` verifies this runtime's Pub/Sub adapter:

```bash
docker run -d --name ghk-pubsub -p 8085:8085 gcr.io/google.com/cloudsdktool/google-cloud-cli:emulators \
  gcloud beta emulators pubsub start --host-port=0.0.0.0:8085 --project=local-project
export GHK_BROKER=pubsub PUBSUB_EMULATOR_HOST=localhost:8085 PUBSUB_PROJECT_ID=local-project
vendor/bin/phpunit --group integration
```

Frontend (`generated-specs/frontend`, image `node:24-bookworm`):

```bash
cd generated-specs/frontend
npm install --no-audit --no-fund --loglevel=error
npm run build
npm test
```

## Production image and cloud deployment

`generated-specs/` has a production `Dockerfile` (multi-stage, non-root user) and a `.dockerignore`. The image is configured only through environment variables, so the same image runs on AWS ECS Fargate, Google Cloud Run, Azure Container Apps or Kubernetes. It listens on port 8000, with one health probe, `/up`, for liveness and readiness.

```bash
cd generated-specs
docker build -t laravel-inertia-vue-auth .
docker run --rm -p 8000:8000 \
  -e DATABASE_URL=postgres://postgres:ghk@host.docker.internal:5432/postgres \
  -e AMQP_URL=amqp://ghk:ghk@host.docker.internal:5672 \
  -e JWT_SECRET='change-me-to-a-secret-of-32-chars!' \
  -e APP_KEY="$APP_KEY" \
  laravel-inertia-vue-auth
curl -f http://localhost:8000/up
```

Set `APP_KEY` in your shell first; in a real deployment it comes from the platform's secret manager.

The runtime kernel chooses its event broker when it starts: `GHK_BROKER` if set, otherwise the broker whose variables are present, otherwise `stack.messaging`.

| Cloud | Broker | Variables |
|---|---|---|
| AWS | Amazon MQ for RabbitMQ | `AMQP_URL` (the broker's `amqps://` endpoint) |
| GCP | Pub/Sub | `GHK_BROKER=pubsub`, `PUBSUB_PROJECT_ID`; the token comes from the workload identity |
| Azure | Self-managed RabbitMQ or CloudAMQP | `AMQP_URL` (there is no official Service Bus SDK for this language) |

The full list of variables and the per-cloud services are in the [deployment guide](https://github.com/FennerEduardo/gherkin-ai-cli/blob/main/docs/DEPLOYMENT.md).

Regeneration replaces only files that are unchanged since they were generated. An edited file is kept, and the new version is written next to it as `<file>.ghk-new`. Review the diff before committing.
